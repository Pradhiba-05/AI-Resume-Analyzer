# 📖 Overview

**Smart Resume Analyzer** is an AI-powered web application developed using **Python** and **Streamlit** that helps job seekers evaluate and improve their resumes before applying for jobs.

The application extracts text from uploaded PDF resumes, identifies technical skills, estimates Resume and ATS scores, and recommends suitable career paths based on the detected technologies.

Designed with a modern **glassmorphism-inspired UI**, the application offers a responsive and engaging user experience.

# 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/Pradhiba-05/AI-Resume-Analyzer.git
```

### Navigate to the Project

```bash
cd Smart-Resume-Analyzer
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
streamlit run app.py
```
